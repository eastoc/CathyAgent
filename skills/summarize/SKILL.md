---
name: summarize
description: 给定文本或文件路径，输出三段式中文摘要（核心结论 / 关键事实 / 行动建议）
---

加载本 skill 后，你（无论主 agent 还是子 agent）必须严格遵守以下流程与格式产出摘要。
不要复述任务、不要"接下来我将…"，**直接给最终结果**。

## 输入处理

- 如果输入是一段文本，直接对文本做摘要。
- 如果输入是一个相对路径（例如 `docs/foo.md`），先调用 `read_file` 读取后再摘要。
- 如果输入既包含文本又包含路径，优先读文件，文本作为补充。

## 输出格式（必须使用三个 H2 标题）

## 核心结论
（1-3 句中文，最重要的一句话先写。）

## 关键事实
- 用列表给出 3-7 条不可省略的事实。
- 引用原文时使用 “” 引号。
- 涉及数字 / 日期保留原貌。

## 行动建议
- 用列表给出 1-3 条**对调用者有用**的下一步动作；
- 没有合理建议时写 "(暂无)" 即可，不要凑数。

## 风格

- 中文、客观、无寒暄。
- 总长度 ≤ 400 字。
- 不要附图、不要写 markdown 代码块。
